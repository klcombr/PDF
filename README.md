# PDFinder

Aplicação web para buscar arquivos PDF na internet de forma rápida e organizada, usando a API Google Custom Search. É voltada para quem precisa encontrar documentos PDF sobre um assunto específico, em português ou inglês.

## Funcionalidades

- Busca de PDFs por assunto.
- Seleção de idioma da busca (português ou inglês).
- Controle da quantidade de resultados (de 1 a 100).
- Resultados exibidos com título e link direto para o PDF.
- Barra de status que mostra mensagens e erros.
- Interface traduzida para português e inglês.

## Como usar

Abra o arquivo `index.html` no navegador. As chaves da API Google Custom Search (`API_KEY` e `CX`) ficam definidas no arquivo `app.js`.

Digite o assunto, escolha o idioma e a quantidade desejada e clique em "Pesquisar".
